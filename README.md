# الجبهة الحديدية

لعبة تصويب تكتيكية أونلاين ثلاثية الأبعاد (منظور الشخص الأول) تعمل في المتصفح على الحاسوب والهاتف.

- معركة فرق: قوات المعارضة ضد قوات النظام، أول فريق يصل إلى 40 قتيلاً أو صاحب أعلى نتيجة بعد 10 دقائق يفوز.
- حتى 16 لاعباً حقيقياً في نفس المعركة، والخادم يكمل كل فريق ببوتات حتى 4 مقاتلين.
- ثلاثة أسلحة: بندقية هجومية، قناصة بمنظار، مسدس — مع ارتداد، تلقيم، وإصابات رأس.
- الخادم هو من يحسب الضرر والنتيجة ويتحقق من الإصابات (المدى، معدل الإطلاق، وجود جدار).

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`. لتغيير المنفذ: `PORT=8080 npm start`.
للعب مع الآخرين شغّل الخادم على جهاز/استضافة يمكن للاعبين الوصول إليها وشاركهم العنوان.

## التحكم

| الحاسوب | الوظيفة |
|---|---|
| W A S D | حركة |
| Shift / Space / C | ركض / قفز / انحناء |
| زر الفأرة الأيسر / الأيمن | إطلاق / تصويب |
| R | تلقيم |
| 1 2 3 أو عجلة الفأرة | تبديل السلاح |
| Tab | لوحة النتائج |

على الهاتف: عصا تحكم يسار الشاشة، سحب على الشاشة لتدوير الكاميرا، وأزرار على اليمين.

## بنية المشروع

- `server.js` — خادم HTTP + WebSocket، منطق المباراة والبوتات.
- `public/shared.js` — الخريطة، الأسلحة، التصادم (مشترك بين الخادم والمتصفح).
- `public/game.js` — العرض (Three.js)، الإدخال، الواجهة، الصوت.
