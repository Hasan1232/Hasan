# الجبهة الحديدية

لعبة تصويب تكتيكية أونلاين ثلاثية الأبعاد (منظور الشخص الأول) تعمل في المتصفح على الحاسوب والهاتف.

- **غرفة العمليات:** خريطة للجبهات تعرض حالة كل جبهة مباشرة، ومنها يختار المقاتل اسمه وطرفه (المعارضة أو النظام) والجبهة التي يقاتل فيها.
- **12 جبهة:** حلب، إدلب، حماة، حمص، دمشق، درعا، دير الزور، الرقة، اللاذقية، طرطوس، الحسكة، السويداء. كل جبهة معركة مستقلة بخريطة مولَّدة بطابع المدينة (لون الحجر، كثافة الدمار، معلم المركز)؛ ليست مخططات شوارع حقيقية.
- **مهمات السيطرة:** في كل جبهة ثلاثة مواقع (أ، ب، ج). الوقوف في الموقع يسيطر عليه، والمواقع تجمع النقاط؛ أول طرف يبلغ 300 نقطة أو صاحب أعلى نتيجة بعد 12 دقيقة يحسم الجبهة.
- حتى 16 لاعباً حقيقياً في كل جبهة، والخادم يكمل كل طرف بمقاتلين آليين حتى 4.
- ثلاثة أسلحة: بندقية هجومية، قناصة بمنظار، مسدس — مع ارتداد، تلقيم، وإصابات رأس.
- الخادم هو من يحسب الضرر والنتيجة ويتحقق من الإصابات (المدى، معدل الإطلاق، وجود جدار).
- القتال بين مقاتلين مسلحين فقط: لا مدنيين، ولا أشخاص حقيقيين، ولا محتوى طائفي.

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`. لتغيير المنفذ: `PORT=8080 npm start`.
للعب مع الآخرين شغّل الخادم على جهاز/استضافة يمكن للاعبين الوصول إليها وشاركهم العنوان.

## التحكم

| الحاسوب | الوظيفة |
|---|---|
| W A S D | حركة |
| Shift / Space / C | ركض / قفز / انحناء |
| زر الفأرة الأيسر / الأيمن | إطلاق / تصويب |
| R | تلقيم |
| 1 2 3 أو عجلة الفأرة | تبديل السلاح |
| Tab | لوحة النتائج |

على الهاتف: عصا تحكم يسار الشاشة، سحب على الشاشة لتدوير الكاميرا، وأزرار على اليمين.

## بنية المشروع

- `server.js` — خادم HTTP + WebSocket، غرفة العمليات، ومعركة لكل جبهة (المواقع، الضرر، البوتات).
- `public/shared.js` — قائمة الجبهات، مولّد الخرائط، الأسلحة، التصادم (مشترك بين الخادم والمتصفح).
- `public/game.js` — العرض (Three.js)، الإدخال، الواجهة، الصوت.

## المجسّمات

`public/models/soldier.glb` هو مجسّم الجندي التجريبي من أمثلة مكتبة three.js (شخصية من Mixamo) ويُستخدم مؤقتاً للطرفين مع تلوين مختلف.
لاستبداله ضع ملف `GLB` آخر بنفس الاسم يحتوي حركات باسم `Idle` و`Walk` و`Run`.
